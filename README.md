# Better Codex 本地轻量版

本项目仅保留 Codex 顶部的归档入口、账号用量，以及聊天输入框的模型快捷选择、加速开关与快捷选项配置。聊天、原生设置和归档列表由 Codex 管理。

模型快捷选项可以调整名称、模型及推理强度，并拖动排序，保存在本机。切换快捷选项保留当前加速状态，闪电按钮单独切换加速。原生模型、权限和设置入口继续可用。

项目管理、总纲、任务规划、任务看板、工作流、智能体管理、Skill 管理、项目 MCP 工具和远程业务功能已移除。历史数据库和聊天保留，不再作为工作流执行源，也不会因打开页面自动发送模型请求。

## 开发与运行

- `npm run status`：核对源码应用状态和本地 Runtime。
- `npm test`：运行保留功能的隔离测试，不发送业务消息。
- `npm run launch`：从固定本地入口打开 Codex。
- `npm run repair`：在空闲时修复本地接入。
- `npm run prepare-local`：校验源码；首次运行时建立本地构建。

`src/ui/` 保存轻量界面与账号元数据恢复，`src/backend/` 保存基础接入 Runtime，`src/modules/` 保存账号传输和运行时支持，`integration/` 保存启动、注入与空闲重载。

源码保存后自动校验及应用；忙碌时等待空闲。`.dev/` 是生成构建、日志和恢复资料，不作为源码编辑。

权威数据目录仍为 `C:\Users\admin\.better-codex`。精简不覆盖数据库，不复制聊天到源码，不修改其他业务项目。移除的托管 Skill 和工作流配置收存在该数据目录下的 `backups/feature-retirement-20261012/`，以后需要时可作为重新规划的参考。
