# Better Codex 本地定制版

本项目提供顶部全局工作流面板、归档入口、账号用量，以及聊天输入框的模型快捷选择、加速开关与快捷选项配置。聊天、原生设置和归档列表由 Codex 管理。

顶部“帮助”右侧的“提示词优化设置”可配置 DeepSeek API Key、模型、优化指令和上下文模式。默认关联当前聊天最近 6 轮用户消息与最终回复（最多 12 条、32000 字，长消息截取并提示），也可选择“仅当前输入”。输入内容后点击“优化提示词”，或在输入框按 `Ctrl + Alt + P`，会把所选上下文与本次输入发送到 DeepSeek 官方接口。优化成功后直接替换输入框，不弹出结果窗口，不自动发送聊天；按一次 `Ctrl + Z` 可还原优化前原文，也可点击“还原原文”。请求期间修改输入或切换聊天时保留当前内容并提示重新优化。工具日志、思考过程、其他聊天和附件不作为上下文发送。无法读取已有聊天上下文时提示重试或切换模式，不悄悄降级。

优化配置单独保存在 `C:\Users\admin\.better-codex\prompt-optimizer-settings.json`，不进入项目源码或历史数据库。API Key 只写入本机配置，读取设置不返回密钥；留空保留现有密钥，可明确清除。测试使用模拟返回，不自动调用真实模型。

优化快捷键可在“提示词优化设置”中点击按键框后直接录入组合键，保存后立即生效，并在重启后保留。默认 `Ctrl + Alt + P`，支持带 Ctrl、Alt 或 Meta 的字母、数字及 F1–F12 组合键；支持恢复默认和禁用快捷键。禁用不影响优化按钮，常用编辑与撤销快捷键不能用于优化。

模型快捷选项可以调整名称、模型及推理强度，并拖动排序，保存在本机。切换快捷选项保留当前加速状态，闪电按钮单独切换加速。原生模型、权限和设置入口继续可用。

“优化提示词”左侧的小清单图标可切换计划模式，点亮表示开启，未点亮表示关闭，状态与原生模式同步。

顶部“帮助”右侧的“面板”打开独立网页。从首页、新聊天或任意已有聊天进入同一个面板，普通关闭只隐藏页面，再次打开保留位置与草稿；数据通过实时事件更新。宿主回收或应用重启后恢复页面位置。页面采用 Codex 夜间配色，支持登记项目、总纲版本、开发任务、AI/人工验收、全项目验收和问题修复复验。

工作流服务独立监听本机，首次启动保存端口，关闭 Codex 不停止服务。新数据保存于 `C:\Users\admin\.better-codex\workflow-v1.db`。旧版工作流已退役，历史数据库和聊天保持原样，不导入新面板。页面打开、MCP 发现和自动测试不发送模型业务请求。

共同 Skill 规范在 `src/skills/` 维护，生成当前用户的 Codex `.agents/skills/` 与 Claude Code `.claude/skills/` 入口。只在明确调用时启用，用项目/任务编号定位，没有任务与会话绑定。总纲和人工验收由页面确认；领取任务获得 30 分钟执行凭证，项目内串行开发，交接需先停止原工具执行，再在面板结束原执行。代码或要求变化后须重新验收。

## 使用工作流

1. 点击“面板”，添加项目名称与本机目录。
2. 创建总纲任务，复制总纲指令到 Codex 或 Claude Code；也可直接编辑草稿、提交并确认版本。
3. 总纲确认后，复制拆分指令生成任务，或手动添加任务。
4. 在任务详情复制开发、AI 验收指令。开发提交后进入 AI 验收，通过后由你在面板完成人工验收。
5. 全部任务完成后创建全项目验收；问题关联新修复任务，修复后人工复验，再确认最新项目验收批次。

Codex 使用 `$bc-charter P001 create`、`$bc-charter P001-T001 continue`、`$bc-plan P001`、`$bc-develop P001-T002`、`$bc-review P001-T002`、`$bc-project-review P001-A001`；Claude Code 将 `$` 换为 `/`。编号以面板实际记录为准。首次安装或配置变更后，使用能发现新 Skill/MCP 的新会话或重启相应客户端；Claude Code 的实际加载需单独验证。

## 开发与运行

- `npm run status`：核对源码应用状态和本地 Runtime。
- `npm test`：运行保留功能的隔离测试，不发送业务消息。
- `npm run launch`：从固定本地入口打开 Codex。
- `npm run repair`：在空闲时修复本地接入。
- `npm run prepare-local`：校验源码；首次运行时建立本地构建。
- `npm run workflow:start / workflow:status / workflow:stop`：启动、检查或停止独立工作流服务。
- `npm run workflow:install`：增量安装当前用户的双客户端 Skill/MCP 配置，保留无关配置并生成恢复备份。

`src/ui/` 保存轻量界面与账号元数据恢复，`src/backend/` 保存基础接入 Runtime，`src/modules/` 保存账号传输和运行时支持，`integration/` 保存启动、注入与空闲重载。

源码保存后自动校验及应用；忙碌时等待空闲。`.dev/` 是生成构建、日志和恢复资料，不作为源码编辑。

权威数据目录仍为 `C:\Users\admin\.better-codex`。精简不覆盖数据库，不复制聊天到源码，不修改其他业务项目。移除的托管 Skill 和工作流配置收存在该数据目录下的 `backups/feature-retirement-20261012/`，以后需要时可作为重新规划的参考。
