先调用 `{{TOOL_PREFIX}}bc_context` 或 `{{TOOL_PREFIX}}bc_project_list` 读取最新项目编号、根目录、状态和 revision。项目 `P001`、任务 `P001-T001`、验收批次 `P001-A001`、问题 `P001-I001` 是永久编号。不要以聊天、窗口、分支、会话 ID 或当前目录代替编号；未给编号时从工具结果确认唯一目标，歧义时请用户选择。

检查实际工作区的绝对根目录与所选项目 local root 一致；存在符号链接或路径大小写差异时比较解析后的真实路径。未匹配时不得修改业务代码。读取该工作区 AGENTS.md 并遵守项目规则，禁止修改其他项目。

写调用带唯一 `requestId` 和目标最新 `expectedRevision`：项目操作用项目 revision，任务操作用任务 revision，批次和问题操作用各自 revision。遇到 revision 冲突先重新读 context，核对是否仍在用户范围内；请求结果不明时只用原 requestId 和完全相同的参数重试，不能生成新 ID 重复变更。

任务阶段需要先 `{{TOOL_PREFIX}}bc_task_claim`，保存服务返回的 `executionId`、`leaseToken`、租约到期时间和最新 revision。租约为 30 分钟，在到期前调用 `{{TOOL_PREFIX}}bc_task_renew`；每次业务文件修改前再次 renew 验证租约及读取返回 revision，长操作期间及时续租。租约失效、撤销、编号不存在或状态不允许时立即停止新的业务修改和提交，重新读取状态；不得越过其他执行者的租约。禁止将 leaseToken 写入提交、日志或面向用户的回复。

证据数组使用 `{kind,result,detail}`。如实区分源码检查、自动测试、浏览器、设备、部署与人工验收；未执行的验证写为未执行，不标通过。调用报错、超时、返回 isError 或服务未确认写入时，不宣称任务已完成；交付说明准确状态、证据与需要人操作的下一步。不得自动发起模型业务请求作为测试。
