# 账号设置请求恢复（2026-10-10）

原生 `/accounts/check/v4-2023-04-27` 曾多次返回 `403 cloudflare_challenge`。同一原生请求客户端、同一登录身份、省略可选 `ChatGPT-Account-ID` 的请求返回 200，且包含当前工作空间。与之后成功的原始查询比较，所选账户的完整记录及角色、成员、停用状态、ZDR 和访问字段均一致。原始请求随后也返回 200，因此只能确认间歇性失败和可行备用请求，不能把工作空间 Header 判定为唯一根因。

`src/ui/native-conversation-adapter.js` 安装一个限定的传输恢复器：原账户明细 GET 遇到上述错误时，保留原生认证、完整性标志、取消信号和身份校验，仅省略可选账户 Header 重试一次。备用响应必须包含所请求的工作空间及必要的成员、访问和权限元数据，之后仍由原生查询和策略检查处理。其他接口、认证错误、工作空间拒绝和政策错误均保持原行为；不采用访客数据、不改查询缓存、不隐藏报错、不发模型请求。

安装使用当前包中的真实 Request 模块；源码重载会恢复旧方法后安装新方法。已核对当前进程安装状态及三个账号查询成功。专项边界测试、原生会话适配器和重载测试通过；当前正常请求没有触发线上备用分支，因此未把测试夹具当作线上拦截恢复证明。

Clash 配置、节点选择、本地端口和 TUN 未修改。本补丁针对账号设置加载，不改变模型 WebSocket 传输，也不代表所有代理线路或未来服务安全验证都已验收。
